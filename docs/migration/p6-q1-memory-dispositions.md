# Q1 memory contract migration dispositions

This is the implemented companion to the approved Q1 specification. It covers all 40 historical methods and 173 explicit predicates: 74 retained invariants (including documented fixture/accessor ports) and 99 approved replacements. No historical method is excluded. Three original budget methods retain both streaming modes. The focused suite now collects 67 cases, including supplemental boundary and preservation coverage.

The JSON companion is the machine-readable exhaustive ledger. Every entry records the frozen original file SHA256, method, line, exact predicate, approved disposition/reason, current replacement node, and actual assertion file/function/line/text. Literal preservation is asserted only for AST-identical predicates. For rewritten predicates the references identify the entire current-owner assertion set, including invoked helpers; they are not claims of one-to-one literal equivalence. The entries below expose the same lineage for human review.

## Contract and fixture ports

Storage-free summary tests use only the synthetic provider transport. Actual source-summary validation, runtime capture, filesystem snapshots, response/source deep copies and explicit subsequent calls establish success and failure. Static summaries have no tools, automatic retries, native continuation, global MEMORY update, or RAW fallback. Preexisting pending bytes are an inert no-access sentinel created after actual MemoryStore construction, not a recovery-admission fixture. Receipt tests instead use authenticated actual recovery layouts and real proof/validation paths.

Governor tests use the real source store, execution owner, writer, request ledger, projection, summary validator and final request guards. Numeric 190/200 boundaries are outcomes of synthetic exact budgets, not restored production caps. Canonical event identity is checked separately from the model payload, whose source-node messages are sanitized. Successful publication changes the header checkpoint/revision while preserving canonical events. Four calls can publish a hard-fitting partial projection even if the 60% target is unmet; overflow and invalid summaries never publish.

Recovery COMPLETE replay retains the receipt and is byte/stat stable; explicit finalization then retains an exact private 0600 copy and seal. An absent second finalization raises. Digest conflicts preserve newer MEMORY/source/cursors/pending but may retain conversion residue; no invented rollback is asserted. Stale offsets preserve all visible targets before conversion.

Retained lock/reducer/session/ring/cron invariants use current owners. The ring's ten literal assertions survive, but removed loop-mirror integration is not covered. Cron uses frozen canonical claims, exact instance tokens, removal result `removed`, addition result `added`, durable reopen and one computation; obsolete jobs.json/callback behavior is not restored. TurnResult uses keyword content. Additional approved fixture ABI ports: SourceCompactionState stream_id=None, MemoryStore.read_memory(), stale.clear() without arguments, and second-manager load only after the seed is durable. SessionWriteConflict and reload/order predicates remain. Pending absence uses memory.memory_dir / '.consolidation.pending.json'.
