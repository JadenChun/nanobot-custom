## Independent authority and Android/native transport

Remote owner starts authority without an agent/gateway ([remote/owner.py:24](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/remote/owner.py#L24)). Its `<data>/remote-access` store uses atomic writes, fsync, private permissions, locks and bounded device audit. Access tokens are short-lived in memory; refresh hashes are durable/rotating, and owner refresh persists until revocation. Challenges and one-use delegations are in memory. Startup revokes legacy chat-only devices; active IPC supports owner-only Full-control pairing ([owner.py:46](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/remote/owner.py#L46), `ipc.py:454`). Historical same-UID Unix IPC has gateway/admin/pair roles: Darwin `LOCAL_PEERCRED`/`SOL_LOCAL` validates xucred size/version/groups; Linux uses `SO_PEERCRED`; unsupported systems are denied (`ipc.py:167`). The refresh supersedes this Darwin claim. Delegation binds `owner:<installation>`, digest, revision, expiry and one use. Mobile identity binds installation/scopes/expiry/generation with uncached delivery checks. DM channel/sender `pairing.json` is a separate authority.

Android MainActivity registers NativeNetworkPlugin ([mobile/android/app/src/main/java/ai/nanobot/mobile/MainActivity.java:23](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/mobile/android/app/src/main/java/ai/nanobot/mobile/MainActivity.java#L23)). Shared WebUI bootstrap awaits native target/tsnet/handshake/refresh; JS receives sanitized outcomes while credentials stay in Kotlin. Custody uses Keystore AES-GCM, origin/installation binding, a separate tsnet-state key and deferred offline revocation ([CustodyStore.kt:108](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/mobile/android/app/src/main/java/ai/nanobot/mobile/network/CustodyStore.kt#L108)). Plugin owns polling, pending calls, WebSocket chunks and shared refresh (`NativeNetworkPlugin.kt:53`). C/JNI typed ABI flows to a Go handle registry and userspace tsnet broker, with bounded configuration/policy, HTTP cancellation/deadlines, one WebSocket session, event queue, streamed media/cache and encrypted atomic state ([broker/core.go:56](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/mobile/native-network/internal/broker/core.go#L56), [state.go:34](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/mobile/native-network/internal/broker/state.go#L34)).
