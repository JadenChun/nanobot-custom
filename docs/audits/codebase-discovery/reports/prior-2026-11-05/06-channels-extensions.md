## Registration and lifecycle

Registry scans packages with manifests; plugin descriptors retain runtime import strings until activation ([nanobot/channels/registry.py:23,55](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/channels/registry.py#L23), [plugin.py:23,74](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/channels/plugin.py#L23)). All 16 non-WebSocket adapters default disabled. `ChannelsConfig` permits channel-owned extra dictionaries parsed by each runtime (`config/schema.py:136`). External entry points are considered only for explicitly enabled sections, rejecting duplicates, missing targets and builtin shadowing (`manager.py:304`). The shared graph builds bus/authority/agent/delivery before channels ([runtime_composition.py:484](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/runtime_composition.py#L484)). `ChannelManager` expands instances, checks dependency metadata, constructs enabled runtimes, and restores state/stops resources on acquisition failure. Gateway starts the loop and `start_all` (`cli/gateway_runtime.py:481,666`). Installation is a separate explicit action ([optional_features.py:742,774](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/optional_features.py#L742)).

[contracts.py:62,157,228](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/channels/contracts.py#L62) separates setup fields, alternative credentials, activation, instances, runtime names, configuration updates and public feature metadata. `_manifest` helpers and the `_setup` resolver feed setup; `connect` supplies the connector/error seam.
