## Config and ownership

Pydantic config accepts camel/snake aliases ([nanobot/config_base.py:12](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/config_base.py#L12)). `load_config` validates JSON, applies compatibility migrations, binds source path and applies SSRF whitelist; missing file yields defaults, malformed existing config raises `ConfigLoadError` ([nanobot/config/loader.py:43,123](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/config/loader.py#L43)). The bound config parent determines instance data/session roots (`nanobot/config/schema.py:998`, [nanobot/runtime_composition.py:192](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/runtime_composition.py#L192)). Environment interpolation is a separate `resolve_config_env_vars`; missing references raise, and CLI exits 1 ([nanobot/config/loader.py:213](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/config/loader.py#L213), [nanobot/cli/runtime_config.py:107](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/cli/runtime_config.py#L107)). This differs from [.agent/gotchas.md:9](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/.agent/gotchas.md#L9); retain the discrepancy for later evaluation.

Schema defaults include `anthropic/claude-opus-4-5`, automatic provider selection, 200 tool iterations, 120000 context tokens, non-unified sessions, unrestricted workspace access and disabled WebSocket channel (`nanobot/config/schema.py:487,896,148`). These are schema facts, not deployment observations.

`RuntimeComposition.define` preflights and defaults to `DurableSessionAuthority` ([nanobot/runtime_composition.py:388](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/runtime_composition.py#L388)). Preflight rejects enabled legacy idle TTL/compaction, checks memory-recovery evidence and existing session modes (:183). Receipt admission accepts clean absence/verified seals and denies uncertain evidence ([nanobot/agent/memory_recovery_startup_admission.py:66](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/memory_recovery_startup_admission.py#L66)). Session authority takes a lifetime writer lease ([nanobot/session/runtime_authority.py:69](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/session/runtime_authority.py#L69)). Acquire binds one loop/thread and constructs/checks the shared object graph ([nanobot/runtime_composition.py:482](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/runtime_composition.py#L482)); cleanup runs closers in reverse, retaining failure when cancellation-resistant work prevents release (:336,623).

## Commands, steering and resource lifetime

Router normalises `/cmd@bot`, has priority/exact/prefix registrations and rejects unknown slash commands ([nanobot/command/router.py:23,110](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/command/router.py#L23)). `/stop`, `/restart`, `/status`, `/quota` are priority bus registrations (`nanobot/command/builtin.py:1116`). Canonical command handling is narrower: `/new` source reset; `/help`, `/model`, `/history`, `/status`, internal `/__shell` dispatch; `/compact` and other commands are unavailable ([nanobot/agent/loop.py:4336](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/loop.py#L4336), `nanobot/command/builtin.py:45`).

Bus follow-up queues cap at 20; canonical WebSocket follow-ups get durable admission identities ([nanobot/agent/loop.py:2610,2714](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/loop.py#L2610)). Runner drains after tool execution and before final stream termination, at most 3 inputs/drain and 5 cycles (`nanobot/agent/runner.py:129,1124,1250`). WebUI target turn is rechecked ([nanobot/agent/loop.py:2853,2136](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/loop.py#L2853)); cleanup republishes leftovers (:2753). Stop records pending dispositions, cancels/joins turn tasks/subagents and owned exec sessions ([nanobot/agent/loop.py:1460](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/loop.py#L1460), `nanobot/command/builtin.py:216`). SDK streaming cancellation cancels/awaits its task ([nanobot/sdk/streaming.py:82](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/sdk/streaming.py#L82)). Runner cancellation propagates after failing source recording (:591); gateway shutdown stops producers and joins tasks before resource close (`nanobot/cli/gateway_runtime.py:279`).

`RunStore` owns bounded atomic JSON under workspace/runs; detailed trace/source references are separate ([nanobot/agent/run_store.py:21,160](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/run_store.py#L21)).
