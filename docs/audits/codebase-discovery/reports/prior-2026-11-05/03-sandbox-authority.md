## Composition and mode separation

Normal tool loading uses `construct_core_tools`, then external plugins, rather than the retained package-discovery API ([nanobot/agent/tools/loader.py:203](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/loader.py#L203)). The historical foreground manifest explicitly constructs filesystem, exec and exec-session tools, then appends optional capabilities (`fork_factories.py:34`). File/exec tools default enabled; exec has a 60-second timeout and empty sandbox backend ([filesystem.py:74](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/filesystem.py#L74), [shell.py:127](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/shell.py#L127)). Global `restrict_to_workspace` defaults false (`nanobot/config/schema.py:896`). Foreground construction shares grants, resource policy, context and file locks, with dependency validation ([nanobot/agent/foreground.py:18,34](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/foreground.py#L18)). Delegated roles omit exec and receive policy-aware file/search tools (`delegation.py:168,346`). Dream has a restricted registry including ApplyPatch, which is absent from foreground construction ([memory.py:622](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/memory.py#L622)).

- Legacy/default shell: an empty backend uses the native shell with application guards; explicit legacy bwrap uses selective mounts. Windows logs an unsupported backend, although admission prerequisites can still deny launch ([shell.py:735,799,943](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/shell.py#L735)).
- Managed WebUI Sandbox: WebSocket gets managed policy before saved-grant-store activation. It requires Linux and usable Bubblewrap; otherwise preparation fails ([nanobot/context_repo/policy.py:74](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/context_repo/policy.py#L74), [shell.py:758](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/shell.py#L758), [sandbox.py:143](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/sandbox.py#L143)).
- Once: a live private task reference supplies task roots. Execution stays bwrap-confined and requires the owned native process supervisor ([shell.py:765,882](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/shell.py#L765)).
- Full: a live private Full reference bypasses the managed wrapper. Owner admission requires the supervisor and no configured legacy sandbox; command-denial rules remain ([nanobot/security/desktop_permissions.py:458](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/security/desktop_permissions.py#L458), [shell.py:702,1258](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/shell.py#L702)).

Mode, grant-store activation and registry filtering are separate. Under `managed_webui_only`, saved external grants apply only to persistent WebSocket sessions; other callers need live task authority ([nanobot/context_repo/policy.py:80,134](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/context_repo/policy.py#L80)). ## File policy and durable grants

The shared resolver expands/resolves symlinks and checks directory or exact-file containment. Exact files reject a logical/resolved-path mismatch ([nanobot/security/workspace_policy.py:24,60,96](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/security/workspace_policy.py#L24)). Tools translate the `/workspace` alias; legacy `extra_allowed_dirs` is read-only, while read/write directories/files are separate ([filesystem.py:53,93](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/filesystem.py#L53)). Managed resolution delegates the resolved path to resource policy ([filesystem.py:240](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/filesystem.py#L240)).

Sandbox is primarily a write boundary: after authority-health/private-state checks, ordinary read/list/exec access is allowed; writes select the most specific baseline, saved or task root ([nanobot/context_repo/policy.py:177,278](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/context_repo/policy.py#L177)). Private state is protected, with a media read/list exception; non-Full access rejects numeric `/proc` PIDs (`policy.py:198,412`). File mutations check policy before writing and share locks. Declared write scopes are independent, listing filters children, and `.env` variants are protected ([filesystem.py:355,1024,1367,1613](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/filesystem.py#L355)). These are application checks, not OS isolation.

`FolderGrantStore` owns saved grants through a file, activation marker, lock and immutable view. Initially missing evidence leaves it disabled; corrupt/incomplete activated evidence is unavailable; fingerprint changes invalidate the view ([nanobot/security/folder_grants.py:161,392,470](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/security/folder_grants.py#L161)). Updates require canonical existing directories, reject private overlap, use revision/native-admission fences and publish snapshots atomically ([folder_grants.py:553,576,677](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/security/folder_grants.py#L553)). Folder catalog and authority updates use an operation journal; catalog success with grant pending is an explicit partial result ([folder_locations.py:126,262](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/security/folder_locations.py#L126)). Workspace focus grants no access ([nanobot/session/workspace_focus.py:455](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/session/workspace_focus.py#L455)).

## Confinement, lifetime and boundaries

Managed bwrap uses a read-only host root, PID namespace, proc/dev/temp overlays, agent home and authorized write roots. It masks repositories/private roots, then restores approved staged inputs ([sandbox.py:172,242](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/sandbox.py#L172)). Input staging bounds files/bytes, copies regular nonsymlink files, revalidates and cleans up ([shell.py:342](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/shell.py#L342)). The legacy command-grant flag does not gate managed launch. Environment curation, deny-first/allowlist checks, desktop-mutation checks, URL-text SSRF checks and resource checks ([shell.py:1209,1258](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/shell.py#L1209)) are not a general network firewall.

Native admission journals starting/active/unknown reservations, owners, boot/PID namespace and receipts. First activation shares the lock and blocks active/unknown state ([nanobot/security/native_admission.py:37,184,409](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/security/native_admission.py#L37)). The Linux supervisor gates child execution on readiness, registered owner and durable acknowledgement ([native_process.py:231](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/native_process.py#L231)). Its subreaper separates root exit, whole-tree quiescence and receipt publication ([native_process_supervisor.py:110,207,381](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/native_process_supervisor.py#L110)). Exec sessions bind the session key, hide unauthorized sessions, recheck private proof before stdin and retain unproven termination ([exec_session.py:382,474,551](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/exec_session.py#L382)). Windows Job assigns a suspended child before resume and kills on close; this does not provide Linux supervisor proof ([_windows_job.py:150](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/_windows_job.py#L150)).

Managed dispatch allows named builtins and exact configured MCP wrappers whose connection owns lifecycle; MCP internals belong to another package (`registry.py:26`). Registry filtering activates on grants/private authority; the stale-unconfined-capability dispatch guard is separate ([nanobot/agent/loop.py:4180](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/loop.py#L4180), `registry.py:76`). The optional-bwrap/native-fallback description in [.agent/security.md:27](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/.agent/security.md#L27) does not cover all managed Once/Full/admission machinery. Displayed enforcement can use environment markers separately from the actual probe ([nanobot/security/workspace_access.py:193](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/security/workspace_access.py#L193), [sandbox.py:143](https://github.com/JadenChun/nanobot-custom/blob/27adced0aacd55d61791bb88a7240d7ad7bd5b75/nanobot/agent/tools/sandbox.py#L143)).
