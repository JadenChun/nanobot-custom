Connected flows and ownership:

- `nanobot.__main__` → `cli.entry.main` → classic Typer application. The callback sets process identity and currently prints help for a bare invocation. Desktop-picker metadata remains in the group, but the entry path does not call the picker. Background gateway/restart/service commands, Desktop TUI attachment, and classic onboarding retain unconditional migration fences.
- Foreground composition constructs a turn-delivery factory and registers the file-edit hook factory. Turn-hook assembly builds progress plus registered/turn hooks; ordinary ephemeral runs skip extra hooks. Delivery binds a capability-filtered sink. This makes file snapshots conditional on a consumer accepting `FileEditEvent`.
- Canonical run context supplies workspace and approval state → `RiskyActionPolicy` → complete-batch evaluation before tool dispatch → hook callbacks → typed output events. Direct callbacks adapt once at the edge. Public SDK trace is separately opt-in and sanitized.
- Configuration loading and environment substitution are separate operations. Runtime CLI loading requests substitution and renders `ConfigLoadError` as an exit. Schema validation removes only disabled retired H1 blocks and invokes local timezone detection only for automatic mode.
- Memory startup admission precedes `MemoryStore` construction and local GitStore access. The shared legacy byte codec belongs to explicit offline conversion/recovery; startup does not invoke the offline reconciliation coordinator. Local trigger audit writes have a concrete helper caller, while the old cron execution/audit seam remains fenced.
- Knowledge save validates its catalog entry, destination and note, publishes the local file under a destination lock, and invokes Git sync only for opted-in paths. Git sync’s common-directory lock and selected-path commit rules are distinct from GitStore’s local memory-index behavior.
- Plugin discovery, enable markers, contributed skills, read authorization and MCP descriptor merge form a separate chain. Mere package presence does not activate contributions. Discovery/marker maintenance may nevertheless touch plugin-data/marker storage.
- Managed process runtime provides common child/state ownership for gateway and WebUI-managed API processes. Gateway service installation is a separate supervisor path; current CLI guards prevent reaching its install/uninstall implementation through those commands.
